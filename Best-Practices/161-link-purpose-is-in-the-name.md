# A link's name says where it goes

A control named here or this does not say what will open.

## Rule

Name a link or button with the destination or the action. The name still matches any visible text.

## Specify

- The controls.
- Their names.

## Check

Move through the links with a screen reader. Each name says what will open. Run it on a mobile client. See [Verify on a mobile client, then record](04-verify-and-record.md).

## Source

Checked 2026-10-19. [Understanding Success Criterion 1.1.1: Non-text Content](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html). The page supports this rule: If non-text content is a control, it has a name that describes its purpose.

Confirm that page before you rely on a platform feature. This practice does not pick a framework, a language, or a platform. A general application rule that any client could use stays in the [application-development knowledge base](https://github.com/erikaskrukauskas/app-dev-knowledge-base).
