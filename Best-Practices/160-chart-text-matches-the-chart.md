# Chart text matches the chart

A chart alternative that says chart of sales does not give the numbers.

## Rule

The text alternative includes the finding or the values the chart exists to show. A long chart can point to a table that has those values.

## Specify

- The chart.
- The text or table.
- That they match.

## Check

Read the alternative without seeing the chart. The same comparison or values are there. Run it on a mobile client. See [Verify on a mobile client, then record](04-verify-and-record.md).

## Source

Checked 2026-10-19. [Understanding Success Criterion 1.1.1: Non-text Content](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html). The page supports this rule: The text alternative serves the equivalent purpose of the non-text content.

Confirm that page before you rely on a platform feature. This practice does not pick a framework, a language, or a platform. A general application rule that any client could use stays in the [application-development knowledge base](https://github.com/erikaskrukauskas/app-dev-knowledge-base).
