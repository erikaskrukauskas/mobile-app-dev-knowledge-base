# An image of words is also text

A picture of a sentence cannot be enlarged, copied, or read reliably.

## Rule

Use real text for words. If a logo contains necessary words, repeat those words as text. Decorative wordmarks that are also on the screen as text can be skipped.

## Specify

- The words that are real text.
- Any image whose words are repeated in text.

## Check

Enlarge text and read the screen with a screen reader. The words are still there as text. Run it on a mobile client. See [Verify on a mobile client, then record](04-verify-and-record.md).

## Source

Checked 2026-10-19. [Understanding Success Criterion 1.1.1: Non-text Content](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html). The page supports this rule: Non-text content needs a text alternative that serves the equivalent purpose. Words are that purpose when the image is carrying words.

Confirm that page before you rely on a platform feature. This practice does not pick a framework, a language, or a platform. A general application rule that any client could use stays in the [application-development knowledge base](https://github.com/erikaskrukauskas/app-dev-knowledge-base).
