# A media clip has a name before it plays

A play button on an unnamed clip does not say what will play.

## Rule

Identify the clip in text before playback. Captions or a transcript still apply when the audio itself carries the message. The name is not a substitute for that transcript.

## Specify

- The name of the clip.
- Where the transcript or captions are, if the audio carries information.

## Check

Find the clip with a screen reader without playing it. The name is announced. Run it on a mobile client. See [Verify on a mobile client, then record](04-verify-and-record.md).

## Source

Checked 2026-10-19. [Understanding Success Criterion 1.1.1: Non-text Content](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html). The page supports this rule: If non-text content is time-based media, text alternatives at least provide descriptive identification of the non-text content.

Confirm that page before you rely on a platform feature. This practice does not pick a framework, a language, or a platform. A general application rule that any client could use stays in the [application-development knowledge base](https://github.com/erikaskrukauskas/app-dev-knowledge-base).
