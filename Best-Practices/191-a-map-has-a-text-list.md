# A map has a text list of the places that matter

A map pin the person cannot see is a place they cannot choose.

## Rule

Provide the same places as a text list with the actions the pins would have offered. The map can stay for people who use it.

## Specify

- The list.
- The actions.
- That the map is not the only path.

## Check

Complete the task from the list with a screen reader, without using the map. Run it on a mobile client. See [Verify on a mobile client, then record](04-verify-and-record.md).

## Source

Checked 2026-10-19. [Understanding Success Criterion 1.1.1: Non-text Content](https://www.w3.org/WAI/WCAG22/Understanding/non-text-content.html). The page supports this rule: The text alternative has to serve the equivalent purpose. For a map whose purpose is choosing a place, the alternative is a way to choose that place.

Confirm that page before you rely on a platform feature. This practice does not pick a framework, a language, or a platform. A general application rule that any client could use stays in the [application-development knowledge base](https://github.com/erikaskrukauskas/app-dev-knowledge-base).
