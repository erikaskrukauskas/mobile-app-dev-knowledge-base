# Contrast is part of the screen contract

Text that is visible on a designer's monitor can disappear in sunlight or for someone with low vision.

## Rule

Name the contrast the text and the essential icons must meet, and check it on a device. Confirm the current criterion before you treat a ratio as the requirement.

## Specify

- The text and icons that carry meaning.
- The contrast they must meet.
- The device check.

## Check

Read the essential text on a phone in bright light and against the named contrast check. Run it on a mobile client. See [Verify on a mobile client, then record](04-verify-and-record.md).

## Source

Checked 2026-10-19. [Build accessible apps](https://developer.android.com/guide/topics/ui/accessibility). The page supports this rule: The Android accessibility getting-started material calls out color contrast, touch target size, and content labeling as practices that make a difference.

Confirm that page before you rely on a platform feature. This practice does not pick a framework, a language, or a platform. A general application rule that any client could use stays in the [application-development knowledge base](https://github.com/erikaskrukauskas/app-dev-knowledge-base).
